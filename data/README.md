# Dataset Information

## VisDrone2019

AerialVision uses the VisDrone benchmark for UAV-based object detection and multi-object tracking research.

**Official source:** https://github.com/VisDrone/VisDrone-Dataset

### Dataset subsets

- VisDrone2019-DET-train
- VisDrone2019-DET-val
- VisDrone2019-DET-test-dev

### Storage

The original dataset files are stored separately in Google Drive and are not included in this GitHub repository because of their size and dataset distribution requirements.

### Usage

Download the dataset from its official source and follow the original dataset organization and annotation format.

Refer to the official VisDrone repository for dataset licensing and usage conditions.
